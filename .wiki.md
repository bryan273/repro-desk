# Project Summary
Repro Desk is a bilingual service for researchers who want to check whether a paper’s headline result can be reproduced. Its landing page explains the process, presents sample reports and free pilot plans, answers common questions, and accepts paper-check requests. An authenticated admin page lets the project owner review and update submitted requests.

The report card and example verdict use illustrative numbers; the three featured images are AI-generated.

# Project Module Description
- **Landing page:** English and Chinese content, with browser-language detection and a remembered language choice. Includes a hero, three-step process, sample report, pricing, FAQ, and request form.
- **Request submission:** Collects a paper link, claim, email, and selected plan. Validates input, saves requests to the database, and returns a request number.
- **Admin:** The `/admin` page lists requests newest first, with status filtering, pagination, and status updates. Only the project owner can access request data; the server enforces this restriction.
- **Authentication:** Handles sign-in, callback, and logout flows. The footer’s “Team login” link leads to the admin page.
- **Backend API:** Provides request, auth, user, settings, storage, health, and AI Hub endpoints.
- **Blog:** Includes blog pages, article rendering, and prerendering utilities.

# Technology Stack
- **Frontend:** React, TypeScript, Vite, Tailwind CSS, and reusable UI components.
- **Backend:** Python and FastAPI, with SQLAlchemy and Alembic for database access and migrations.
- **Authentication and platform integrations:** Atoms Cloud Web SDK and backend services.
- **Testing and quality:** ESLint, Playwright configuration, and frontend plugin tests.

# Usage
Install frontend dependencies from `app/frontend` using the package manager corresponding to the lockfile, then use the scripts defined in `package.json` to run the development server, lint, or build the frontend.

Install backend dependencies from `app/backend` in a Python virtual environment using `requirements.txt`. Configure the required database, authentication, and platform environment settings before starting the backend. Apply database migrations with Alembic when setting up or updating the database.

`app/start_app_v2.sh` is provided as an application startup helper. The frontend production build and lint checks passed during implementation. Real request submission and admin login have not been verified.
